# Сервис управления рассылками

Простой проект для создания и управления рассылками сообщений пользователям.

## **Что делает проект**

* Регистрация и вход пользователей.
* Есть роли: обычный пользователь, менеджер и суперпользователь.
* Обычный пользователь видит только свои рассылки.
* Менеджер видит всех пользователей, может блокировать их и управлять рассылками.
* Суперпользователь видит всё и может управлять всеми данными.

## **Рассылки**

* Создаёшь рассылку с сообщением и выбираешь получателей.
* Можно включать и отключать рассылку (`is_active`).
* Отправка писем фиксируется в статистике (успешные и неуспешные попытки).
* Можно запускать рассылку вручную через админку.

## **Статистика**

* Главная страница показывает:
    * Всего рассылок
    * Активные рассылки
    * Уникальные получатели
    * Всего попыток отправки
    * Успешных и неуспешных попыток

## **Блокировка пользователей**

* Менеджер может заблокировать пользователя через админку.
* Заблокированный пользователь не может войти в систему.

## **Кеширование**

* Главная страница кешируется 60 секунд, чтобы уменьшить нагрузку на сервер.
